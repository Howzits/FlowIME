# FlowIME 兼容性验证

本表区分规则测试、系统接口检查与实际界面上屏，不能用一类结果代替另一类。

## 已完成的自动检查

- 默认/已安装布局选择：包括仅中文输入法、默认英式布局与缺失布局。
- 查找控件保护：Webview/Monaco 查找结构标识、可访问标签、聊天/终端祖先优先级、控件重建和离开后的正常切换。
- 输入规则：终端优先、普通输入框、聊天中的 Monaco、代码区和只读区域保持。
- 会话偏好：输入框隔离、保持模式、128 项上限与清除。
- 扩展生命周期与本地化：14 项 Node 测试，涵盖重试、暂停、配置更新、分段状态消息、诊断/偏好命令传输和中英文界面。
- 手动偏好观察：早期手动变化、自动请求失败/延迟、单次抖动、未知状态、反向切换及重置。
- 焦点防抖：用可控时间验证稳定等待、快速往返、离开应用、受保护区域、焦点句柄/规则变化、命令与清除，以及检查间隔。
- Windows 原生助手编译、VSIX 文件结构检查和隔离安装。

## 怎样收集可复现证据

1. 运行 `FlowIME: 诊断输入框（3 秒后采集）`，在 3 秒内点击目标控件。
2. 保存输出面板的诊断行，记录 Windows、VS Code、聊天扩展和输入法版本。
3. 实际试打并记录中文/英文结果。`observed` 是 Windows 传统 IME 接口的参考值，不能当作 TSF 输入法的真实状态证明。
4. 对比离开/返回控件、手动切换、清除偏好前后的结果。

开发者也可以运行 `./test/compatibility.ps1 -Label codex-chat`，在 5 秒内点击目标控件。脚本只读采集焦点规则和参考状态，不打字、不切换输入法，结果写入本地忽略目录 `.validation/compatibility.jsonl`。标签中不要填写聊天正文或隐私信息。
